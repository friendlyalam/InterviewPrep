# Algorithm

## Definition

An Algorithm is a step-by-step procedure used to solve a problem.

In simple words,

An Algorithm is a sequence of steps to achieve a goal.

------------------------------------------------------------

Real-Life Example 1

Making Tea

Step 1
Boil water.

Step 2
Add tea leaves.

Step 3
Add sugar.

Step 4
Add milk.

Step 5
Boil.

Step 6
Filter.

Step 7
Serve.

These steps together form an algorithm.

------------------------------------------------------------

Real-Life Example 2

Google Maps

You enter a destination.

Google Maps calculates the best route.

It follows an algorithm.

------------------------------------------------------------

Technical Example 1

Searching for an employee by EmployeeId.

There are many possible algorithms.

Linear Search

Binary Search

Hash Lookup

Each solves the same problem differently.

------------------------------------------------------------

Technical Example 2

Sorting employee salaries.

Different algorithms include

Bubble Sort

Merge Sort

Quick Sort

Each produces the same result but with different performance.

------------------------------------------------------------

Important Points

An algorithm should

• Solve the problem

• Produce the correct result

• Finish after a finite number of steps

• Be efficient

One problem can have multiple algorithms.

The best algorithm usually performs the task faster or uses less memory.
