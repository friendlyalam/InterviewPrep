# Input

## Definition

Input is the information or data provided to a program or algorithm so that it can perform a task and produce the desired result.

## Simple Definition

Input is the information given to solve a problem.

## Why Do We Need Input?

Without input, an algorithm has nothing to process. Every program requires one or more inputs to perform meaningful work.

## Characteristics

- Input is the starting point of every algorithm.
- Input may come from a user, file, database or another system.
- A program may have one input, multiple inputs or no input.
- Input can be validated before processing.
