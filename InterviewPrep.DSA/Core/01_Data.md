# Data

## Definition

Data is a collection of facts, values, or information that can be stored and processed by a computer.

In simple words,

Data is any information that a computer can understand and use.

Examples

Name : Alam

Age : 35

Salary : 100000

Marks : 95

Email : abc@gmail.com

All of these are data.

------------------------------------------------------------

Real-Life Example 1

A student's report card contains:

- Name
- Roll Number
- Class
- Marks

These are all pieces of data.

------------------------------------------------------------

Real-Life Example 2

Your Aadhaar card contains:

- Name
- Date of Birth
- Address
- Aadhaar Number

This information is data.

------------------------------------------------------------

Technical Example 1 (C#)

string name = "Alam";
int age = 35;
double salary = 100000;

These variables store data.

------------------------------------------------------------

Technical Example 2

A SQL Server table stores

EmployeeId
EmployeeName
Department
Salary

Each row in the table is data.

------------------------------------------------------------

Important Points

• Data can be numbers.

• Data can be text.

• Data can be dates.

• Data can be images.

• Data can be videos.

• Data can be files.

Without data, software cannot work.
