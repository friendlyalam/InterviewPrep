Array — Problem 6: Find the Second Largest Element

Given an integer array, return the second largest distinct element in the array.

Examples
Input:  [10, 20, 30, 40, 50]
Output: 40

Input:  [10, 50, 20, 50, 30]
Output: 30

Input:  [5, 5, 5]
Output: No second largest element

Requirements
Handle null input appropriately.
Handle an empty array appropriately.
The second largest must be distinct from the largest.
Handle duplicate values.
Handle negative numbers.
