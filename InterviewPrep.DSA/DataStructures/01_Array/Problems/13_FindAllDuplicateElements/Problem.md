Array — Problem 13: Find All Duplicate Elements

Given an integer array, find all elements that appear more than once.

Return the duplicate values only once.

Examples
Input:  [1, 2, 3, 2, 4, 1, 5]
Output: [1, 2]

Input:  [5, 5, 5, 5]
Output: [5]

Input:  [1, 2, 3, 4, 5]
Output: []

Input:  [-1, 2, -1, 3, 2, 2]
Output: [-1, 2]

Requirements
Handle null input appropriately.
Handle an empty array appropriately.
A value appearing 2 or more times should appear only once in the result.
Negative numbers and zero are allowed.
Don't use LINQ.
Try to think about time complexity and space complexity before coding.
