Array — Problem 9: Check if an Array Is Sorted

Given an integer array, determine whether the array is sorted in ascending order.

Return:

true  → if the array is sorted
false → if the array is not sorted
Examples
Input:  [1, 2, 3, 4, 5]
Output: true

Input:  [1, 2, 2, 4, 5]
Output: true

Input:  [1, 3, 2, 4, 5]
Output: false

Input:  [5, 4, 3, 2, 1]
Output: false

Input:  [7]
Output: true

Requirements
Handle null input appropriately.
Handle an empty array appropriately.
A single-element array is considered sorted.
Duplicate values are allowed.
Negative numbers and zero are allowed.

Do not sort the array to solve the problem.
