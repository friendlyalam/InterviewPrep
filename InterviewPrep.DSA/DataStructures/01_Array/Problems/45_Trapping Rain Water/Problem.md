Problem 45 — Trapping Rain Water

Given an array height where height[i] represents the height of a vertical bar, calculate how much rainwater can be trapped after raining.

Each bar has width 1.

Example 1
Input:
height = [0,1,0,2,1,0,1,3,2,1,2,1]

Output:
6
Example 2
Input:
height = [4,2,0,3,2,5]

Output:
9
Example 3
Input:
height = [1,2,3,4]

Output:
0
Constraints
1 <= height.Length <= 100000
0 <= height[i] <= 100000
Return the total amount of trapped water.
