Array — Problem 8: Reverse an Array

Given an integer array, reverse the elements in place and return the reversed array.

Examples
Input:  [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]

Input:  [10, 20]
Output: [20, 10]

Input:  [7]
Output: [7]

Input:  [-1, 0, 5, -10]
Output: [-10, 5, 0, -1]

Requirements
Handle null input appropriately.
Handle an empty array appropriately.
Handle a single-element array.
Reverse the array in place.

Try to avoid creating another array.
