Array Problem 28 — Maximum Consecutive Ones
Problem Statement

Given a binary array nums containing only 0 and 1, find the maximum number of consecutive 1s in the array.

Return the maximum count.

Examples

Example 1

Input:  [1,1,0,1,1,1]
Output: 3

Example 2

Input:  [1,0,1,1,0,1]
Output: 2

Example 3

Input:  [0,0,0]
Output: 0

Example 4

Input:  [1,1,1,1]
Output: 4
Requirements
The array contains only 0 and 1.
Return the length of the longest consecutive sequence of 1s.
You do not need to modify the input array.
Constraints
1 <= nums.Length <= 100,000
nums[i] is either 0 or 1
