Array — Problem 15: Find the Missing Number

Given an array containing distinct numbers from 0 to n, with exactly one number missing, find and return the missing number.

Examples
Input:  [3, 0, 1]
Output: 2

Input:  [0, 1]
Output: 2

Input:  [9, 6, 4, 2, 3, 5, 7, 0, 1]
Output: 8

Input:  [0]
Output: 1

Requirements:
Handle null input appropriately.
Handle an empty array appropriately.
Numbers are distinct.
Values are from 0 to n.
Exactly one number is missing.
Do not modify the input array.
Do not use LINQ.
Try to think about time and space complexity before writing your solution.

Constraints
1 <= nums.length <= 10⁵
0 <= nums[i] <= n
All numbers in nums are unique.
Exactly one number from [0, n] is missing.
Modify the array in-place if your approach requires modification.
Return the missing number.
