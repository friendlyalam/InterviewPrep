Array Problem 16 — Single Number

Given a non-empty integer array nums, every element appears exactly twice except for one element that appears exactly once.

Find and return the element that appears only once.

Examples

Example 1

Input:  nums = [2,2,1]
Output: 1

Example 2

Input:  nums = [4,1,2,1,2]
Output: 4

Example 3

Input:  nums = [1]
Output: 1
Constraints
1 <= nums.length <= 10⁵
-10⁵ <= nums[i] <= 10⁵
Every element appears exactly twice except one element.
The solution must return the element that appears only once.
