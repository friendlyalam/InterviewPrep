Array — Problem 4: Count Even Numbers

Given an integer array, return the number of even elements in the array.

Examples
Input:  [1, 2, 4, 7, 10]
Output: 3
Input:  [3, 5, 7]
Output: 0
Input:  [-2, -5, 0, 8]
Output: 3
Requirements
Handle null input appropriately.
Handle an empty array appropriately.
The array can contain positive, negative, and zero values.
