Array — Problem 10: Count Occurrences of a Given Element

Given an integer array and a target integer, count how many times the target appears in the array.

Examples
Input:  [1, 2, 3, 2, 2, 5], target = 2
Output: 3

Input:  [10, 20, 30, 40], target = 5
Output: 0

Input:  [5, 5, 5, 5], target = 5
Output: 4

Input:  [-2, 3, -2, 0, -2], target = -2
Output: 3

Requirements
Handle null input appropriately.
Handle an empty array appropriately.
The target can be positive, negative, or zero.
If the target doesn't exist, return 0.
Count all occurrences.
Do not use LINQ's Count() to solve it.
