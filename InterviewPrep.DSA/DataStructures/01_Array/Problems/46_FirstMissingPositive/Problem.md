Problem 46 — First Missing Positive

Given an unsorted integer array nums, find the smallest missing positive integer.

The solution should run in O(n) time.

Example 1
Input:
nums = [1, 2, 0]

Output:
3
Example 2
Input:
nums = [3, 4, -1, 1]

Output:
2
Example 3
Input:
nums = [7, 8, 9, 11, 12]

Output:
1
Example 4
Input:
nums = [1, 2, 3]

Output:
4
Constraints
1 <= nums.Length <= 100000
nums[i] can be negative, zero, or positive.
The array may contain duplicates.
The optimal solution should use O(1) extra space apart from the input array.
