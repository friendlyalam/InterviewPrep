Problem 50 — Maximum Sum Circular Subarray

This is your 50th problem and deliberately adds another important variation of Kadane's algorithm rather than repeating normal Maximum Subarray (#19).

Problem

Given a circular integer array, find the maximum possible sum of a non-empty subarray.

Because the array is circular, the subarray can wrap from the end back to the beginning.

Example
Input:
[5,-3,5]

Output:
10

The maximum circular subarray is:

[5] + [5]

= 10
