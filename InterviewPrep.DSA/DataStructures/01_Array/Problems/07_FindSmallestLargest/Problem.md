Array — Problem 7: Find the Smallest and Largest Element

Given an integer array, find both the smallest and largest elements.

Examples
Input:  [10, 5, 20, 3, 15]
Output:
Smallest = 3
Largest  = 20


Input:  [-10, -5, -20, 0]
Output:
Smallest = -20
Largest  = 0


Input:  [7]
Output:
Smallest = 7
Largest  = 7

Requirements
Handle null input appropriately.
Handle an empty array appropriately.
Handle one element.
Handle positive, negative, and zero values.
You need to find both values in a single traversal if possible.
