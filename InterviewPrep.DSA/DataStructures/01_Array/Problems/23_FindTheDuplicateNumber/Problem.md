Array Problem 23 — Find the Duplicate Number
Problem Statement

Given an array nums containing n + 1 integers where each integer is in the range [1, n], return the one number that appears more than once.

There is exactly one duplicated number, but it may appear more than twice.

You must find the duplicate without modifying the array.

Examples

Example 1

Input:  [1,3,4,2,2]
Output: 2

Example 2

Input:  [3,1,3,4,2]
Output: 3

Example 3

Input:  [1,1]
Output: 1
Constraints
nums.Length = n + 1
Every value is in the range [1, n]
Exactly one number is duplicated
The duplicated number may appear more than twice
The array must not be modified
Try to solve it without using extra arrays, HashSet, or Dictionary.
