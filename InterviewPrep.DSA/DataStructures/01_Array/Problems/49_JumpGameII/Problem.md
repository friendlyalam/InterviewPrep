Problem 49 — Jump Game II
Problem

You are given an integer array nums.

nums[i] represents the maximum number of positions you can jump forward from index i.

Starting from index 0, return the minimum number of jumps required to reach the last index.

Assume the last index is always reachable.

Example
Input:
[2,3,1,1,4]

Output:
2

Explanation:

0 → 1 → 4

2 jumps
