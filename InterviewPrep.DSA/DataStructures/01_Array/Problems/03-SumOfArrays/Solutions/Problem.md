Array — Problem 3: Sum of Array Elements

Difficulty: Easy

Problem Statement

Given an integer array, return the sum of all elements in the array.

Examples

Example 1

Input:  [10, 20, 30, 40]
Output: 100

Example 2

Input:  [-5, 10, -3]
Output: 2

Example 3

Input:  [50]
Output: 50
Constraints

The input array can contain positive, negative, and zero values.

Handle invalid input appropriately.
