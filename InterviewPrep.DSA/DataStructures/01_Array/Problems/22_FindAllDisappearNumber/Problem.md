Array Problem 22 — Find All Numbers Disappeared in an Array

Given an array nums of n integers where each integer is in the range [1, n], return all the integers in the range [1, n] that do not appear in nums.

Examples

Example 1

Input:  nums = [4,3,2,7,8,2,3,1]
Output: [5,6]

Example 2

Input:  nums = [1,1]
Output: [2]

Example 3

Input:  nums = [1,2,3,4,5]
Output: []
Constraints / Requirements
nums contains n integers.
Every integer is in the range [1, n].
Some numbers may appear more than once.
Return all numbers from 1 to n that are missing.
The order of the returned missing numbers should be ascending.
Handle:
Duplicate numbers
No missing numbers
One missing number
Multiple missing numbers
All elements being the same
Do not assume the array is sorted.
