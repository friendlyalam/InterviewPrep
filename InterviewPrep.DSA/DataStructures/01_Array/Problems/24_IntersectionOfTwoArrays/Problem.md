Array Problem 24 — Intersection of Two Arrays II
Problem Statement

Given two integer arrays nums1 and nums2, return an array containing their intersection.

Each element in the result must appear as many times as it shows in both arrays.

The order of the result does not matter.

Examples

Example 1

Input:
nums1 = [1,2,2,1]
nums2 = [2,2]

Output:
[2,2]

Example 2

Input:
nums1 = [4,9,5]
nums2 = [9,4,9,8,4]

Output:
[4,9]

Example 3

Input:
nums1 = [1,2,3]
nums2 = [4,5,6]

Output:
[]
Constraints
nums1 and nums2 may contain duplicates.
A number should appear in the result only as many times as it appears in both arrays.
The result can be returned in any order.
Handle:
duplicate values
no intersection
one common value
multiple common values
different array lengths
empty arrays
