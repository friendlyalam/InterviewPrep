Problem Statement

Given an integer array containing only 0, 1, and 2, sort the array in ascending order.

You must solve it in-place, meaning you should not create another array for the final result.

Examples
Input:  [2, 0, 2, 1, 1, 0]
Output: [0, 0, 1, 1, 2, 2]

Input:  [2, 0, 1]
Output: [0, 1, 2]

Input:  [0, 0, 1, 2, 2]
Output: [0, 0, 1, 2, 2]

Requirements
Array contains only 0, 1, and 2.
Sort in ascending order.
Modify the original array.
Return the sorted array.
Handle null and empty arrays with validation.
