# .NET and CLR Interview Questions

# 1. What is .NET?

.NET is a cross-platform development platform containing:

- Runtime
- Libraries
- SDK
- Tooling
- Application frameworks

---

# 2. What is CLR?

CLR is the runtime environment responsible for executing managed .NET code.

Major responsibilities:

- JIT
- GC
- Memory management
- Exception handling
- Type/runtime services
- Assembly loading
- Interoperability

---

# 3. Explain the complete C# execution pipeline.

Answer:

```text
C# Source Code
      ↓
C# Compiler
      ↓
IL/CIL + Metadata
      ↓
Assembly
      ↓
CLR loads assembly
      ↓
JIT
      ↓
Native Machine Code
      ↓
CPU

This is one of the most important answers to memorize.

4. What is IL?

IL = Intermediate Language.

It is a CPU-independent intermediate representation generated by the compiler.

Also called:

CIL
MSIL
5. Is IL machine code?

No.

IL is intermediate code.

JIT normally converts IL into native machine code.

6. What is JIT?

JIT = Just-In-Time compiler.

It converts IL into native machine code during runtime.

7. What is an assembly?

A compiled .NET unit containing things such as:

IL
Metadata
Manifest
Resources

Common assembly files:

.dll
.exe
8. Assembly vs Namespace
Namespace

Logical grouping of types.

Assembly

Compiled deployment/runtime unit.

They are not the same.

9. What is metadata?

Metadata describes types and members in compiled assemblies.

Examples:

Classes
Methods
Properties
Fields
Interfaces
Signatures
References
10. What is reflection?

Reflection allows runtime inspection of types and members.

Example:

Type type = typeof(Customer);

foreach (var property in type.GetProperties())
{
    Console.WriteLine(property.Name);
}
11. What is managed code?

Code whose execution is managed by the .NET runtime.

12. What is unmanaged code?

Code/resources operating outside normal CLR-managed execution.

Examples:

Native libraries
Native memory
OS handles
13. What is GC?

Garbage Collector.

It automatically reclaims managed memory from objects that are no longer reachable.

14. What are GC generations?
Gen 0
Gen 1
Gen 2

They help the GC manage objects according to approximate lifetime.

15. Can .NET have memory leaks?

Yes.

Example:

static List<object> cache = new();

If objects remain referenced indefinitely, GC cannot collect them.

16. GC vs Dispose
GC

Manages managed object memory.

Dispose

Releases resources deterministically.

17. What is IDisposable?

Interface used to expose deterministic resource cleanup.

Example:

using FileStream stream = File.OpenRead(path);
18. Does Dispose free managed memory immediately?

No.

Dispose releases resources owned by the object.

The object itself is collected later when it is no longer reachable.

19. Does async/await create a new thread?

No.

async/await is an asynchronous programming model.

For I/O operations, it can allow a thread to be released while the operation is pending.

20. Does Task mean Thread?

No.

Task represents an asynchronous operation.

A Task may use a ThreadPool thread for CPU work, but asynchronous I/O can complete without occupying a worker thread for the entire wait.

21. .NET vs CLR
.NET
 ├── Runtime
 ├── Libraries
 ├── SDK
 └── Tools

CLR
 └── Runtime execution environment
22. CLR vs JIT
CLR

Runtime environment.

JIT

Component responsible for converting IL to native code during execution.

23. C# Compiler vs JIT
C# Compiler
C#
 ↓
IL + Metadata
JIT
IL
 ↓
Native Code
24. JIT vs AOT
JIT

Compilation during runtime.

AOT

Compilation before execution.

25. What is BCL?

Base Class Library.

Examples:

List<T>
Dictionary<TKey,TValue>
Task
File
Stream
String
HttpClient
Exception
26. NuGet package vs Assembly
NuGet

Package/distribution mechanism.

Assembly

Compiled .NET unit.

A NuGet package may contain one or more assemblies.

27. CLR vs Operating System
Application
    ↓
CLR
    ↓
Operating System
    ↓
Hardware

CLR does not replace the OS.

28. Does CLR provide ASP.NET Core?

No.

ASP.NET Core is a higher-level web framework running on .NET.

29. Does CLR provide EF Core?

No.

EF Core is a .NET data-access framework/library.

30. Does CLR provide LINQ?

No.

LINQ functionality is provided by .NET libraries.

32. Senior-Level Question

Question:

An ASP.NET Core service has high CPU and frequent GC. What would you investigate?

Answer areas:

1. Allocation rate
2. Object lifetime
3. Large allocations
4. Gen 0/1/2 collections
5. LOH usage
6. Allocation-heavy code
7. Serialization
8. String allocations
9. Excessive temporary objects
10. Caching/object retention
11. CPU hotspots
12. Runtime profiling

Do not immediately change GC configuration.

Measure first.

33. Senior-Level Memory Question

Question:

Application memory keeps increasing but GC is running. Why?

Possible explanation:

GC can only reclaim unreachable objects.

Investigate:

Static references
Caches
Event subscriptions
Long-lived objects
Unbounded collections
Incorrect lifetimes
Timers/background references
